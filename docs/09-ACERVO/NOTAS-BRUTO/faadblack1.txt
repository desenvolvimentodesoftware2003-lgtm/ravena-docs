Iteração por Categoria: O processo de clusterização percorre cada categoria (DESCRICOES_CATEGORIA) da base de conhecimento.
Criação de Clusters: Para cada categoria, são gerados clusters semânticos usando o algoritmo K-Means com base nos embeddings das perguntas existentes. Cada item de conhecimento recebe um cluster_id.
Identificação de Clusters Pequenos: Após a criação dos clusters, o sistema verifica o tamanho de cada um. Se um cluster tiver menos de 3 itens, ele é considerado "muito pequeno" e necessita de reforço.
Geração de Variações Semânticas: Para esses clusters pequenos, a função gerar_variacoes_semanticas é invocada. Ela seleciona um item "representativo" do cluster (atualmente, o primeiro item encontrado no cluster) e utiliza o modelo Gemini (gemini_model) para criar novas perguntas e respostas parafraseadas que mantêm o mesmo sentido. Por padrão, são geradas 2 variações por cluster pequeno.
Aprendizado e Reforço: Cada uma dessas variações geradas é então "aprendida" pela Raven, usando a função aprender_informacao. Isso significa que as novas variações são adicionadas à base de conhecimento, com seus respectivos embeddings e metadados, efetivamente aumentando a quantidade de exemplos semânticos para aquele conceito e, consequentemente, melhorando a capacidade da Raven de reconhecer perguntas semelhantes no futuro.
