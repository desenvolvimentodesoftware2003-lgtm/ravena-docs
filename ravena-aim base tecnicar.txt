Arquitetura em 4 Camadas
Camada	‐	Principais
Percepção	Captura de dados de mercado e sinais	signal_bridge, bybit_connector,active_vision
Cognição	Análise, RAG e tomada de decisão	omega_core, rag_advanced,trade_brain
Execução	Operações de negociação e automação	click_emulator, risk_manager,social_connector
Governança	Segurança, auditoria e compliance	security_core, hacker_agent, auditor,zero_trust
Filosofia: Soberania Híbrida
A Ravena opera com independência local (pode operar offline) enquanto se beneficia de inteligência em nuvem quando disponível. O sistema nunca depende de um único ponto de falha externo.

Modo Soberano: Operação 100% local com modelos embarcados
Modo Híbrido: Combina LLMs em nuvem com validação local
Modo Nuvem: Orquestração completa via OCI
Agentes Especialistas Integrados
Agente de Busca 360 ( search_agent_v3.2.6.py): Buscas abrangentes em múltiplas fontes
Agente Dev ( agente_dev_v3.2.6.py): Auxílio em manutenção e manutenção
Agente de Chat ( ravena_chat_agent_v3.2.6.py): Interface conversacional natural
Agente Hacker ( hacker_agent.py): Red Team automatizado para testes ofensivos
Agentes Especializados ( specialized_agents_v3.2.6.py): Módulos sob demanda
Implantação (Oracle Cloud Infrastructure)
Pré-requisitos
Docker e Docker Compose instalados
Conta OCI com compartimento configurado
Chaves API da Bybit (testnet para beta)
Início rápido
# 1. Clonar repositório
git clone https://github.com/desenvolvimentodesoftware2003-lgtm/ravena-aim.git
cd ravena-aim

# 2. Configurar variáveis de ambiente
cp .env.example .env
# Editar .env com suas credenciais

# 3. Subir com Docker Compose
cd docker
docker-compose up -d

# 4. Verificar saúde
docker-compose ps
curl http://localhost:8000/health

Protocolo R6: 6 camadas de validação de integridade
